# Art-Museum-Database
Instructions for how to install and use the program:

First, mySQL and XAMPP need to be installed.
To install the program, first run the create.sql file and load.sql file. This will create the tables in the database and define the constraints, foreign keys, and primary keys.

Then, opening the home.html file using the local host will provide access to the all of the relevant .html links relevant to Artworks, Artists, Exhibitions, Donors, and Staff.

Artworks:
Add artworks by entering relevant information into the form from "Add new artwork" and clicking submit. Artworks can also be searched for by entering the artwork name in the "Search artworks" form.

Artists:
Artists can be added by entering relevant information and clicking submit using the "Add new artists" form. The "Search artists" form can be used to search for artists using their last name.

Exhibition:
Exhibitions can be added under the "Add new exhibition" form. The artworks to be included in the exhibition need to added at the same time. Click "add another artwork" enough times so there are enough fields for the number of artworks desired to be added to the exhibition.

Donors:
Donors can be added by entering the relevant information in the form "Add new donor." Donors can also be searched for using the donors last name under for the "Search donors" page.

Staff:
There are two types of staff- administrators and exhibition staff. To add a new administrator fill out relevant information using the "Add new administrator." Information can be updated using the "Update administrator" form. It works the same way for Exhibition Staff using the "Add new Exhibition Staff" and "Update Exhibition Staff" forms. Employees can be searched for using the "Search for employee" form by using their first and last name.
